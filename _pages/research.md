Code
======
* [Rep the Set](https://github.com/y3nk0/repset): neural networks for learning set representations (AISTATS 2020)
* [OMP for Text Classification](https://github.com/y3nk0/OMP-for-Text-Classification): orthogonal matching pursuit for text classification (W-NUT @ EMNLP 2018)
* [Multi-label Classification with Deep Learning](https://github.com/y3nk0/Multi-label-with-Deep-Learning): implementation of the ADIOS paper in Python 3.5 and Keras 2.2.0
* [Theano CNN for Text Classification](https://github.com/y3nk0/Theano-CNN): Python 3.5, supports all datasets, multi-class
* [TensorFlow CNN for Text Classification](https://github.com/y3nk0/Tensorflow-CNN): Python 3.5
* [GraKeL: Graph Kernels in Python](https://ysig.github.io/GraKeL/dev/index.html): Python 2.7 and 3.5 (JMLR 2020)
* [Graph-Based Feature Extraction](https://github.com/y3nk0/Graph-Based-TC): graph-based term weighting for text categorization, Python 2.7
